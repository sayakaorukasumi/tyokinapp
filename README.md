# さやの貯金アプリ 💰

ブラウザで動く、シンプルでかわいい貯金アプリです。

## 特徴
- 現在の貯金額と目標金額を入力・保存（ブラウザの localStorage に保存）
- 貯金額に応じてステージ（画像・タイトル・メッセージ）が切り替わる
- スマホでも見やすいピンク系のUI

## 使い方
`index.html` をブラウザで開くだけ。インストール不要です。

## ステージの編集
`stages.js` の `STAGES` 配列を編集するだけで、
ステージの金額・画像・文言をかんたんに変更できます。

各ステージのフィールド:
| フィールド | 内容 |
| --- | --- |
| `threshold` | このステージになる貯金額（円）の下限。小さい順に並べる |
| `title` | ステージ名 |
| `image` | 絵文字（例 `"🐣"`）または画像パス（例 `"images/stage1.png"`） |
| `message` | 応援メッセージ |

画像を使う場合は `images/` フォルダに入れて、`image` をパスに書き換えます。

## ファイル構成
- `index.html` … 画面
- `styles.css` … デザイン
- `stages.js` … ステージ設定（ここを編集）
- `app.js` … ロジック
- `images/` … ステージ画像置き場
